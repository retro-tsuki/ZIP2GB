# ZIP2GB

## 概要
### 日本語
Googleドライブ等を経由して「ただ.zipのファイル」になってしまったGarageBandプロジェクトを、iOSが認識できる「パッケージ（フォルダ）」の状態に復元します。[GB2MIDI](https://github.com/larkob/GB2MIDI)から感銘を受け制作しました。
### ENGLISH
This tool restores GarageBand projects that have become "just .zip files" via Google Drive, etc., back to a "package (folder)" state that iOS can recognize. It was inspired by [GB2MIDI](https://github.com/larkob/GB2MIDI).

## ツールへはこちら/Tool Access Here
[ZIP2GB](https://retro-tsuki.github.io/ZIP2GB/)
or https://retro-tsuki.github.io/ZIP2GB/

## 使い方/How to Use
### 日本語
1. 復元したい.zipファイルを選択
2. 「.band形式で復元」を押す
3. ダウンロードされたファイルをApple公式の「ファイル」アプリで解凍する（解凍はダウンロードされたファイルをタップすることで完了します。）
### ENGLISH
1. Select the .zip file you want to restore.
2. Press ".band形式で復元"(in English Restore in .band format).
3. Unzip the downloaded file using the "Files" app by Apple(unzipping is completed by tapping the downloaded file).
